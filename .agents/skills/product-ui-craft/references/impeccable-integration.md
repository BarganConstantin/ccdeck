# Adaptive Impeccable integration

Discover the enabled skills catalog and read the installed Impeccable entrypoint. Do not guess its location, copy its implementation or alter its installation. Record its version from available metadata, actual supported workflow names, owning reference and invocation mechanism.

Some versions expose instruction workflows, not shell executables. Read and apply the referenced workflow through the agent's supported skill mechanism; run supporting scripts exactly as documented. Never execute guessed slash commands in a shell or claim an unavailable command ran. Load session context once where required and follow its delegation, preservation and bounded-review rules within user authorization.

The observed 4.1.1 installation supports shape, critique, audit, layout, typeset, colorize, clarify, adapt, harden, polish, distill, bolder, quieter, animate and delight. Its craft command is a deprecated alias for ordinary new-work. This is a compatibility example, not a guarantee for another installation; verify again when using a different version.

| Evidence | Candidate workflow; select only what is needed |
|---|---|
| New interaction/architecture | shape or documented new-work workflow |
| Poor hierarchy | critique → layout/typeset |
| Sterile but usable composition | critique → colorize; bolder only with a purposeful direction |
| Crowded decisions | critique → distill/layout; preserve essential actions |
| Narrow/short failures | adapt/harden |
| Inconsistent component craftsmanship | polish plus incumbent token/control review |
| Confusing copy | clarify, grounded in actual semantics |
| Weak interaction feedback | interaction review; animate only if feedback benefits the task |
| Aggressive noise | quieter selectively |
| Release readiness | audit → harden for proven edges → polish for demonstrated optical defects |

Do not automatically run the entire catalog. A workflow must name its target and problem, produce findings and contribute to actual implementation or verification. Keep an honest provenance note (read/applied, script executed, unavailable), not an inflated command checklist.

Without Impeccable, continue with this skill's review rubric, state/data inventory, incumbent design system, browser evidence and quality gates. Do not install dependencies or pause merely because an optional collaborator is missing. Missing specialist guidance reduces what can be claimed, not the obligation to finish authorized work.
