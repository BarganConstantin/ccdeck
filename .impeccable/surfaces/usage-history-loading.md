# Usage history loading

Mode: Operate. Keep ccdeck's existing modal, chart, palette and controls.
Owner direction (2026-10-19): an animated loading illustration with the same
care as Radio's opening state, appropriate to usage history.

The reserved chart space contains a small line illustration: local documents,
three outlined packets moving toward an empty report frame, then the real
report replaces it as soon as the request resolves. It communicates reading
local logs without fabricated values, staged percentages or a minimum delay.
The baseline remains static. Existing chart arrival motion is retained.

Use current theme text/line/accent tokens. A single 1800ms packet loop runs only
while busy, pauses with document visibility, and becomes three static packets
under reduced motion. Expose one named loading status; SVG content is decorative.
Keep range, refresh and Close usable. Same-range refresh retains the current
chart; only initial loading or a changed range shows the illustration.
